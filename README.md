# Hi, I'm Ali 👋

I'm a network and systems engineer with a Master's in Computer Architecture.  
I enjoy building at the boundary of hardware, performance, and machine learning — especially for distributed and edge environments.

## What I work on

- **Distributed ML systems**  
  Federated and decentralized pipelines for real networked systems, with focus on privacy, synchronization, and deployment trade-offs.

- **High-performance computing**  
  GPU-side optimization (CUDA and Apple Silicon MPS), memory behavior, and end-to-end bottleneck analysis.

- **Hardware + software engineering**  
  From RTL design to ML deployment, with emphasis on reliability, efficiency, and scalability.

## Featured projects

### Decentralized Traffic Prediction (Fed-STGNN)
**[Decentralized-Traffic-Prediction](https://github.com/Ali-Yazdanpanah/Decentralized-Traffic-Prediction)**
